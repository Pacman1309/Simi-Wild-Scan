# Diagramas derivados del SDD

Los originales definitivos del equipo están en [../../diagramas_autoritativos](../../diagramas_autoritativos/). Estos archivos Mermaid son vistas auxiliares alineadas con ellos y no los sustituyen.

Fuentes editables en Mermaid:

| Archivo | Diagrama |
|---|---|
| [architecture_context.mmd](architecture_context.mmd) | Contexto del sistema |
| [deployment.mmd](deployment.mmd) | Despliegue GCP y dispositivo |
| [use_cases.mmd](use_cases.mmd) | Actores y casos de uso |
| [domain_er.mmd](domain_er.mmd) | Entidades y relaciones |
| [class_domain.mmd](class_domain.mmd) | Clases de dominio |
| [activity_report.mmd](activity_report.mmd) | Actividad de creación de reporte |
| [activity_moderation.mmd](activity_moderation.mmd) | Actividad de moderación |
| [sequence_online_report.mmd](sequence_online_report.mmd) | Secuencia de envío online |
| [sequence_offline_sync.mmd](sequence_offline_sync.mmd) | Secuencia de sincronización offline |
| [report_state.mmd](report_state.mmd) | Estados de reporte |

El equipo puede renderizarlos en Mermaid Live, la extensión de su editor o la herramienta académica requerida, conservando los Draw.io como fuente de verdad.
